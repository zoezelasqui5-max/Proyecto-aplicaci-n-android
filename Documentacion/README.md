# Documentación del proyecto AgendaDeTurnos

Esta carpeta contiene la documentación correspondiente al proyecto final de la asignatura Desarrollo de Aplicaciones Móviles.

## Contenido

- Presentación final del proyecto.
- Informe final de desarrollo.
- Wireframes y diseños de la aplicación.

## Descripción

AgendaDeTurnos es una aplicación Android desarrollada en Kotlin que permite gestionar reservas, consultar disponibilidad, visualizar turnos y programar reservas recurrentes.
